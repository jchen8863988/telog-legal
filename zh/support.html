1. 产品与运营主体

  • TeLog（特档案） 是由独立个人开发者运营的 iOS 应用，帮助特斯拉车主在本机建立车辆档案、记录行程充电、使用应急与用车助手，并可选开通 Cloud 深度能力。
  • 本 App 非特斯拉官方产品。车辆数据仅在您通过特斯拉官方授权链接后取得；默认保存在您的手机本机。
  • 运营者通过特斯拉中国区官方开发者平台（developer.tesla.cn）正规取得 Fleet API 资格，在您主动授权后方可读取车辆数据。
  • 联系邮箱：service@telog.cn

4. 数据原则：官方授权 · 默认本机

  1. 首次同意：首次启动须在「用户协议与隐私保护」页点击同意后方可使用；详细免责与责任限制见在线《用户协议》《隐私政策》。
  2. 官方授权：连接车辆时在特斯拉官方页面登录并勾选权限。
  3. 默认本机：Fleet API 数据经处理后默认仅存本机加密数据库。
  4. 可选云端：云端代采 / 备份 / 家庭共享等须单独同意，通常需 Cloud 会员。

5. 特斯拉官方授权链路

  1. 运营者在 developer.tesla.cn 注册应用并取得 Fleet API 资格；
  2. 您在官方认证页（如 auth.tesla.cn）明示授权；
  3. App 在授权范围内调用 Fleet API；未经授权无法访问车辆数据；
  4. 我们不收集您的特斯拉密码。

API 可用性、配额与字段以特斯拉公布为准；变更或中断时我们将合理协助您重新授权。

6. 数据存储、导出与删除

  • 默认：本机加密存储，不上传业务服务器。
  • 导出：设置 → 隐私与数据 → 导出全部数据（JSON）。
  • 删除本机：清空本地数据（请先备份）。
  • 停止云端：停止云端并删除远端副本；本地不受影响。
  • 断开授权：高级设置断开连接，并建议在特斯拉侧撤销第三方应用。

8. 发送反馈指南

  1. 打开「设置 → 关于与支持 → 发送反馈」；
  2. 选择相关组件（App 功能简称），填写问题描述、发生时间；如需截图请开启提示并在邮件中手动添加附件；
  3. 点「发送」→ 调起系统邮件，收件人自动为 service@telog.cn，主题与正文预填；
  4. 在系统邮件中确认后发送。

请尽量提供：iPhone 型号与 iOS 版本、TeLog 版本、是否已连接特斯拉 / Cloud 状态、可复现步骤。请对 VIN、车牌、家庭地址等打码。

10. 常见问题

打不开「发送反馈」邮件？

请先在系统「邮件」中添加邮箱账号，再重试。

数据存在哪里？会上传吗？

默认仅本机。仅当您单独同意云端功能后，才会有加密副本存于境内服务器。

如何删除数据？

「隐私与数据」导出或清空；或邮件联系 service@telog.cn。

行程有空白？

车辆休眠、网络中断或 App 未运行可能导致本机漏采。可考虑 Cloud 云端代采或导入历史数据。

订阅退款？

由 Apple 处理。我们可确认订阅是否有效，但无法代为退款。
