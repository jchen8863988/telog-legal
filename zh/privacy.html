2. 一句话原则

  • 数据来源唯一官方路径：车辆相关数据仅来自您通过特斯拉官方 OAuth / Fleet API 授权后，由本 App 依法调用官方接口取得；我们不收集、不存储您的特斯拉账号密码。
  • 默认仅存本机：未经您另行单独同意，车辆遥测、行程、充电、轨迹等默认加密保存在您的手机本机，不上传至运营者业务服务器作云端存档。
  • 可选云端须再同意：Cloud 会员的云端代采、备份同步、家庭共享等能力，须另行明示同意后方可启用。
  • 不做广告跟踪：不集成广告 SDK，不出售个人信息，不在 App 内进行跨应用跟踪。

3. 中国合规与苹果分发标准

运营者按中国个人信息保护要求与 Apple App Store Review Guidelines 中隐私相关最高实践组织产品，包括但不限于：

  • 合法正当必要：仅处理实现车辆档案、记录、分析、应急与支持等功能所必需的信息。
  • 告知—同意：首次启动展示「用户协议与隐私保护」确认页，须点击同意后方可继续；敏感功能（位置、云端、家庭共享等）单独同意；可撤回。摘要以在线全文为准。
  • 用途限定：不将车辆数据用于广告定向或与核心功能无关的画像。
  • 用户可查可控：App 内提供导出、清空本机、停止云端并删除远端副本、发送反馈与邮箱联系渠道。
  • Privacy Nutrition Labels：App Store 隐私标签将与本政策一致披露；如功能变更，运营者将同步更新标签与本页。
  • 账号删除路径：您可通过「隐私与数据」清空本地数据并请求删除云端副本；亦可邮件提出删除请求。

4. 车辆数据如何取得（特斯拉官方授权）

TeLog 通过运营者在特斯拉中国开发者平台 （developer.tesla.cn） 正规注册的第三方应用，在您授权后读取车辆数据。典型链路：

环节说明是否经 TeLog 业务服务器中转车辆遥测
开发者注册 运营者注册应用并取得 Fleet API 资格与 client_id —
车主授权 您跳转特斯拉官方认证页（通常为 auth.tesla.cn）登录并勾选 OAuth 范围 否
Token 换票 授权码 / refresh token 经运营者 HTTPS token 代理换取 access token；client_secret 仅存服务端，不进安装包 仅令牌交换，不含车辆遥测内容
车辆数据拉取 App 直连特斯拉 Fleet API 获取车辆状态等数据 否（默认模式）
本机处理 解析、行程/充电生成、统计与展示默认在您的设备完成 否
可选云端代采 仅在您单独同意且具备 Cloud 资格时，境内服务可代拉并加密备份补采 是（可选）

4.1 可能申请的 OAuth 范围（以授权页为准）

  • openid、offline_access、user_data
  • vehicle_device_data — 车辆状态、电池、充电、里程、软件版本等
  • vehicle_location — 车辆位置（行程轨迹、地理围栏）
  • vehicle_cmds、vehicle_charging_cmds — 仅在您主动使用唤醒、预空调、定时充电等指令时

您可随时在特斯拉账户或本 App 中断开授权。

4.2 自 Fleet API 衍生的信息类型

  • 车辆识别：VIN、显示名称、在线/休眠/行驶/充电状态
  • 位置与行驶：GPS、航向、速度、档位、功率；衍生行程与轨迹点
  • 电池与续航：SOC、续航估算、里程表
  • 充电：状态、功率/电流/电压、已充入电量、充电上限等
  • 车辆状态：OTA、车门锁车、哨兵、胎压、空调等
  • 您在 App 内创建的内容：围栏名称、备注、电价、路书打卡、反馈内容等

精确位置、行程轨迹、VIN 等可能构成敏感个人信息；我们仅在明确、合理目的下，并在您连接车辆或开启相关功能而作出的同意范围内处理。

7. 默认本机存储与可选云端

7.1 默认：仅本机

连接特斯拉后，Fleet API 返回的数据经处理后 默认仅保存在您设备的加密本地数据库（如 SQLite）中， 不上传至我们的业务服务器进行存储或分析。卸载 App、清空本地数据或删除设备备份后，本机数据随之删除。

7.2 可选：云端代采 / 备份（Cloud 会员）

仅在您阅读《云端代采数据处理说明》并单独勾选同意，且通常具备有效 Cloud 会员资格时：

  • 境内服务可能代您调用 Fleet API，补采手机离线期间的行程与充电数据；
  • 用途：连续记录、统计、备份与跨设备同步；不用于广告；
  • 您可随时关闭；关闭后停止上传并删除境内服务器副本（本机数据保留）。

7.3 可选：家庭共享

与云端代采分开同意。仅当您确认相关说明后，受邀且获相应权限的成员方可查看您授权范围内的车辆信息；您可随时撤销。

7.4 保存期限

  • 本机数据：至您卸载、清空或更换设备并删除备份。
  • OAuth token：加密存本机；refresh 交换经 HTTPS 代理。
  • 云端副本（如已开启）：中华人民共和国境内；默认滚动保留约 365 天，关闭后删除服务器副本。
  • 支持邮件：为处理问题合理保留，一般不超过 24 个月，法律要求更长者除外。

8. 地图与位置相关服务

为在中国大陆合法提供地图展示、围栏与地址文字化，TeLog 可使用 高德开放平台（lbs.amap.com） 依法申请的服务（Web 地图 / Web 服务 API 等），并遵守测绘与地图管理相关规定。 可能向高德传输经转换的坐标与渲染参数；不会向高德传输特斯拉密码或 OAuth token。

当高德不可用且您允许时，App 可能将坐标回退至 OpenStreetMap Nominatim 等服务；该回退非默认首选。 详情见高德开放平台隐私政策。

12. 未成年人保护

TeLog 面向成年车主及车辆管理人，不会主动面向未满 14 周岁未成年人收集个人信息。 若监护人发现误收集，请联系我们删除。

13. 安全措施

  • 本机加密存储与设备系统级保护（屏幕锁 / Face ID 等由您的设备负责）；
  • client_secret 不进安装包；HTTPS 传输；
  • 云端副本加密与访问控制（启用时）；
  • 最小权限：按功能所需申请 Fleet API scope；
  • 发生安全事件时，将依法告知并采取补救措施。

互联网环境并非绝对安全，请妥善保管设备与 Apple ID。
