1. Product & operator

  • TeLog is an iOS app by an independent indie developer for Tesla owners: on-device vehicle archive, drives/charges, emergency helpers, optional Cloud depth features.
  • Not Tesla official. Vehicle data only after official Tesla authorization; stored on-device by default.
  • Contact: service@telog.cn

2. Contact

Support / privacy: service@telog.cn

In-app: Settings → About & support → Support email (display) · Technical support (this page) · Send feedback (opens system Mail).

First reply: typically within 48 business hours (mainland China holidays may delay).

Privacy requests: same inbox, subject “Privacy request”; aim ≤15 business days.

Support URL:
https://jchen8863988.github.io/telog-legal/en/support.html

We never ask for Tesla passwords, SMS codes, full refresh tokens, bank cards, or Apple ID passwords.

If system Mail has no account yet, add one in the Mail app before using Send Feedback.

4. Data principles

  1. Official Tesla authorization only.
  2. On-device encrypted storage by default.
  3. Optional cloud / family sharing needs separate consent (usually Cloud membership).

5. Tesla authorization

  1. Operator registers on developer.tesla.cn and obtains Fleet API access.
  2. You authorize on Tesla’s official auth page.
  3. App calls Fleet API within granted scopes.
  4. We do not collect your Tesla password.

6. Storage, export, deletion

  • Default: on-device only.
  • Export / wipe under Privacy & data.
  • Stop cloud deletes remote copies; local remains.
  • Disconnect Tesla in Advanced settings; also revoke third-party access in Tesla account when possible.

7. Cloud membership

  • com.jchen.Telog.plus.monthly (~¥18/mo) · com.jchen.Telog.plus.yearly (~¥198/yr)
  • 14-day trial if offered by App Store

Free examples: live status · emergency/lights · VIN/tires · latest 15 drives · latest 2 charges · basic stats · standard share · OTA history · TOU rates

Cloud examples: smart always-on logging · full history · 21 dashboards · battery health/value · attribution · driving reports · Passport · family share · expense · road trip · geofence/parking · sync/backup · PDF/Excel · premium share

After expiry, free local features remain; Cloud-only features pause. Local data is not deleted. Billing/refunds via Apple.

8. Send Feedback

  1. Settings → About & support → Send feedback
  2. Select a component (short feature name), describe the issue and when it happened; attach screenshots manually in Mail if needed
  3. Send → system Mail opens to service@telog.cn with prefilled content

Include iPhone model, iOS version, TeLog version, Tesla/Cloud status, and steps. Mask VIN, plate, home address.

9. Support scope

We help with: install/crashes, Tesla official auth & refresh, local record import/export, optional cloud revoke, Cloud status explanation, privacy requests, feedback email issues.

Not us: roadside / Tesla service, Tesla password recovery, Apple hardware/Apple ID, professional appraisal based on App data.

10. FAQ

Mail won’t open?

Add an account in the system Mail app first.

Where is my data?

On-device by default. Cloud copies only after separate consent, stored in mainland China.

How do I delete?

Privacy & data, or email service@telog.cn.

Gaps in trips?

Sleep/network/App not running can miss local capture—Cloud collection or historical import may help.

Refunds?

Apple only. We can confirm entitlement status.
